# Manual de Usuario - Avicultura Inteligente
1. Ingrese a `http://127.0.0.1:8000/` con las credenciales de prueba (`admin` o `productor`).
2. Gestione granjas y lotes desde el menú superior.
3. Registre producción diaria, alimentación, movimientos de inventario, ingresos/gastos y condiciones ambientales.
4. Consulte reportes filtrando por lote y rango de fechas.
